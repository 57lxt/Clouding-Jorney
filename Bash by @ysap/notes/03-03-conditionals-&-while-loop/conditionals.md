# Conditionals

* equals ```==```
* negation ```!```
* -f - checks if file exists
*  

### Example
```bash
read "Enter 1st num: " num1
read "Enter 2nd num: " num2
if [[ $num1==$num2 ]]; then
  echo 'the numbers are equal'
else
  echo 'the numbers are not equal'
fi
```
