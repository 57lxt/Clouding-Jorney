# Vim Configration
Resources: https://github.com/romainl/idiomatic-vimrc

## Files and Directories
1. system - default vim config
2. user - located at ```$HOME/.vimrc``` or ```$HOME/.vim/.vimrc```

## Vim's Documentation
```bash
:help :command
:help function()
:help 'option'
:help i_ctrl-a
:helpgrep foo
:help get<C-d>
Press <C-]> (Ctrl+]) on a highlighted tag to jump to the corresponding entry
Press <C-t> (Ctrl+t) to come back
```
